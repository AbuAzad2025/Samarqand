# واجهة سمر قند (React/Vite)

```powershell
npm install
npm run dev      # http://127.0.0.1:5173 مع proxy إلى Django على 8000
npm run build    # يكتب الناتج مباشرة في ../../website/static/website/samarqand_spa/
npm run typecheck
npm run lint
```

البناء موجود مسبقاً في المستودع؛ لا حاجة لإعادة بنائه للتشغيل المحلي العادي.
لوحة التحكم متاحة على `/control/dashboard` بعد تسجيل دخول مستخدم staff.
