# مصادر الشعارات

المجلد هذا يحفظ **الملفات الأصلية** للشعارات فقط. النسخ المُحسّنة المستخدمة في الموقع موجودة في:

`website/static/website/brand/`

## سمر قند
| الملف | الاستخدام |
|---|---|
| `wordmark-dark-source.png` | الشعار العريض على الخلفيات الداكنة (الفوتر) |
| `wordmark-light-source.png` | الشعار العريض على الخلفيات الفاتحة |
| `icon-source.png` | الأيقونة المربعة (favicon / لوحة التحكم) |
| `icon-variant-source.png` | نسخة بديلة للأيقونة |
| `square-poster-source.png` / `profile-poster-source.png` | مواد تسويقية، لا تُستخدم في الواجهة |

## أزاد للأنظمة الذكية
| الملف | الاستخدام |
|---|---|
| `wordmark-dark-source.png` | شعار المطوّر في الفوتر |
| `wordmark-alt-source.png` | نسخة بديلة بالإنجليزية |
| `icon-source.png` | أيقونة المطوّر |

## قاعدة
- لا تُعدّل الأصول الأصلية؛ أنشئ نسخة مُحسّنة في `website/static/website/brand/`بالحجم المناسب.
- أصول المنصة (favicon، manifest، service worker، أيقونات PWA) تبقىمنفصلة في `website/static/website/` و`frontend/samarqand/public/`، وليست داخل مجلدات العلامات التجارية.
