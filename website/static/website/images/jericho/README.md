# صور مشروع تأهيل قاعة الوصول – استراحة أريحا

نسخ محسّنة (WebP) من صور حقيقية للمشروع الجاري، مصدرها مجلد المشروع لدى الشركة.

- `cover.webp`: أعمال الحفر والتأسيس لقاعة الوصول — المصدر: `image 15-10-2026\WhatsApp Image 2026-10-15 at 14.13.20 (5).jpeg`
- `site.webp`: موقع العمل خلال مرحلة التأسيس — المصدر: `image 17-10-2026\img (14).jpeg`
- `steel.webp`: تجهيز الوحدة الصحية لصب الخرسانة — المصدر: `image 18-10-2026\تجهيز الوحدة الصحية لصب الخرسانة.jpeg`
- `canopy.webp`: تركيب هياكل المظلة الحديدية الجنوبية — المصدر: `images 09-11-2026\تركيب جسور وهياكل المظلة الحديدية الجنوبية المستحدثة (3).jpeg`
- `finishes.webp`: استكمال أعمال البلاط لأرضية القاعة — المصدر: `image 22-10-2026\استكمال اعمال البلاط لارضية القاعة.jpeg`

لا تُستخدم هذه الصور لمشاريع أخرى، ولا تُعدّل محتواها.
